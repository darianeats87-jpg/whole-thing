# mangaHUB

Click **Manga** in the navigation.

- **Catalog:** a list of manga with search. It comes from AniList, with Jikan (MyAnimeList) as a backup. Adult titles are excluded.
- **Title page:** synopsis, status and genres, plus "Read on ..." buttons for the official sites AniList lists (for example MANGA Plus or Webtoon).
- **Chapters:** English chapters are looked up on MangaDex through its public API. Click a chapter to read it in the built-in reader (vertical pages, Prev / Next, arrow keys, Esc to close). Chapters that MangaDex only links to an official site open that site in a new tab.
- If MangaDex is down, or the title is not there, the page says so and the official links still work.

The page title changes to **mangaHUB** while you are in the manga view.

## Small windows
If the top bar runs out of room, the least-used buttons move into a **☰** menu automatically, so nothing is cut off at any window size.
